Прошити з браузера

  1. Відкрийте цю сторінку в Chrome або Edge на комп'ютері (потрібен Web Serial).
  2. Підключіть плату кабелем USB-C, що передає дані.
  3. Натисніть кнопку й виберіть порт плати (USB JTAG/serial debug unit).
Цей браузер не вміє Web Serial: відкрийте сторінку в Chrome або Edge на комп'ютері. This browser has no Web Serial: open the page in Chrome or Edge on a computer. Потрібне з'єднання HTTPS. · HTTPS is necessary.

Порту немає в списку? Плата, що спить, не відповідає на USB. Затисніть BOOT, натисніть і відпустіть RESET (або перепідключіть кабель), відпустіть BOOT — плата чекає на прошивку. Після прошивання натисніть RESET.

Перше прошивання: погодьтеся стерти пристрій (erase). Потім підключіться до точки доступу RLCD-Setup-… (QR-код на екрані) і пройдіть майстер першого налаштування.

No port in the list? A sleeping board does not answer on USB: hold BOOT, press RESET (or plug the cable again), release BOOT. On the first install, erase the device, then connect to the RLCD-Setup-… access point and follow the first-start wizard.
